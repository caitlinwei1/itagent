audience: employee
status: active
updated: 2026-03-19
---
1. Restart (many issues clear after an update finishes installing).
2. Free disk space if less than 10% is free: empty Downloads and Recycle Bin/Trash, use OneDrive "Free up space".
3. Check Task Manager / Activity Monitor for one app using most CPU.
4. Still slow after 1-3: hardware check by Endpoint & Workplace Support (book via the agent).
