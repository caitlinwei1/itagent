title: "Lost or stolen laptop or phone"
systems: [Laptop]
symptoms: [security]
audience: employee
status: active
updated: 2026-08-28
---
Report it immediately. Security Operations can remote-lock or wipe managed devices; the helpdesk agent escalates as P1 with the asset ID, when and where it was lost, and whether it was locked. If it was stolen, also file a police report and send the reference number to Security.
